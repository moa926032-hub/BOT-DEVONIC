# 🚀 Installation

### Termux (Android)

```bash

pkg update -y && pkg upgrade -y
pkg install git nodejs -y
git clone https://github.com/moa926032-hub/BOT-DEVONIC.git
cd BOT-DEVONIC 
npm install
npm start
```
