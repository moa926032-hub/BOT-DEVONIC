١) التشغيل السريع
────────────────────────────────────────────

على تيرمكس (أندرويد):

    pkg update && pkg upgrade -y
    pkg install -y nodejs git ffmpeg python
    git clone https://github.com/moa926032-hub/BOT-DEVONIC.git
    cd BOT-DEVONIC
    npm install
    npm start

على لينكس / VPS:

    sudo apt update && sudo apt install -y nodejs npm ffmpeg python3
    git clone https://github.com/moa926032-hub/BOT-DEVONIC.git
    cd BOT-DEVONIC
    npm install
    npm start

بعد التشغيل: أدخل رقم الواتساب، سيظهر كود اقتران،
أدخله من الواتساب ← الأجهزة المرتبطة ← ربط جهاز ← الربط برقم الهاتف.

للفحص قبل التشغيل:

    npm run check


────────────────────────────────────────────
٢) ما الذي تم إصلاحه في هذا الإصدار
────────────────────────────────────────────

• أوامر التحميل والبحث: كانت كلها معطلة لأن المعالج لم يكن
  يمرر الوسائط (args) للأوامر، فكل أمر يحتاج مدخلات كان يفشل صامتاً.
  الآن يتم تمريرها بشكل صحيح.

• أمر menu: كان يُرسل كرسالة قائمة (list message)، والواتساب
  لم يعد يسلّم هذا النوع لحسابات البوتات، فلم يظهر شيء.
  أُعيد بناؤه كقائمة نصية مرتبة بأقسام + صورة ترويسة.

• مصادر التحميل الميتة: أُزيلت المكتبات والواجهات المتوقفة
  (meowsab، كائن Api غير الموجود، واجهات تيك توك المحجوبة)
  واستُبدلت بمحرك موحد:
      المحرك الأساسي   : yt-dlp محلياً
      المحرك الاحتياطي : سلسلة مزودات خارجية مختبرة
  فإذا حجب يوتيوب السيرفر (رسالة Sign in to confirm you're not a bot)
  ينتقل البوت تلقائياً للمزود الاحتياطي ويكمل التحميل بنجاح.

• تحويل الترميز: بعض المزودات تعيد فيديو بترميز AV1 لا يُشغّل
  على كل الأجهزة، فيتم تحويله تلقائياً إلى H.264/AAC.

• أمر البريفكس: كان يعيد كتابة ملف config.js بالكامل فيمسح
  كل الإعدادات ويرجع الاسم القديم. الآن يحفظ البريفكس في
  data/prefix.txt فقط دون المساس بأي إعداد.

       - إن فشل        ← يتوقف عن تنفيذ الأوامر ويُنبّه المستخدم

────────────────────────────────────────────
٤) أهم الأوامر (البريفكس الافتراضي: نقطة)
────────────────────────────────────────────

القائمة:
    .menu / .اوامر            القائمة الكاملة
    .اوامر <القسم>            أوامر قسم محدد

التحميل:
    .تحميل <رابط>             تحميل من أي منصة مدعومة
    .تحميل صوت <رابط>         تحميل الصوت فقط
    .اغنيه <اسم>              بحث بالاسم + تحميل صوت
    .فيديو <اسم>              بحث بالاسم + تحميل فيديو
    .يوتيوب <رابط>            يوتيوب
    .تيك <رابط>               تيك توك بدون علامة مائية
    .انستا <رابط>             إنستغرام
    .فيس <رابط>               فيسبوك
    .سبوتيفاي <رابط>          سبوتيفاي
    .ميديافاير <رابط>         ميديا فاير

البحث:
    .بحث <كلمة>               بحث يوتيوب
    .بحث_تيك <كلمة>           بحث تيك توك
    .بين <كلمة>               بحث صور  (ويمكن .بين قطط | 5)
    .انمي <اسم>               بحث أنمي
    .اخبار_انمي               أخبار الأنمي

أخرى:
    .بريفكس <رمز>             تغيير البريفكس (للنخبة فقط)
